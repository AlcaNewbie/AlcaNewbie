### 🗣️ About Me

Saya adalah **developer berusia 15 tahun** asal Parung, Bogor, yang berfokus pada **Full-Stack Web Development, Automation Scripting, dan Web Scraping**. Berawal dari rasa penasaran dan eksplorasi mandiri, coding kini menjadi kebiasaan harian untuk membangun aplikasi web yang fungsional dan solusi otomatisasi yang efisien.

- ⚡ **Full-Stack & Web Scraping:** Terbiasa membangun aplikasi web modern menggunakan **Next.js, React, Tailwind CSS, dan Supabase**, serta merancang *web scraper* presisi tinggi untuk ekstraksi data mentah.
- 📱 **Portable & Terminal Coder:** Mengandalkan **Termux, MT Manager, dan Cloud Environments** sebagai lingkungan kerja portabel utama untuk mengeksekusi skrip Node.js/Python, pengolahan file, dan otomatisasi dari mana saja.
- 🛠️ **Reverse Engineering & Game Modding:** Berpengalaman mengembangkan skrip kustom berbasis Lua untuk **GTA SAMP (MonetLoader)**, analisis logika API, hingga simulasi sirkuit hardware (Arduino) di Tinkercad.
- 🎵 **Vibe & Aesthetic:** Menyukai estetika *dark mode* (palet `#191919`), tampilan terminal UI/glassmorphism, serta ditemani alunan musik Alternative Rock & R&B saat ngoding.
